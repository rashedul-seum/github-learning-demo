# Git Learning Notes

## Concepts Learned

- Git tracks the history of a project.
- GitHub stores a remote version of a Git repository.
- A commit represents a checkpoint.
- Staging determines what will be included in the next commit.

## Commands Learned

`git status` shows the current repository state.

`git add` stages changes.

`git commit` records staged changes.

`git push` sends local commits to GitHub.

## Current Goal

Learn a professional Git and GitHub workflow.

## Remote Synchronization

A Git repository can be cloned to multiple computers and synchronized through GitHub.

## Collaboration Practice

Git allows researchers to collaborate safely on shared code.
